# Code of Conduct / 行为准则

## Our pledge / 我们的承诺

The QuietReader community welcomes people who contribute in a respectful and constructive way. We are committed to making project spaces comfortable for everyone, regardless of background or experience.

QuietReader 社区欢迎以尊重、建设性的方式参与项目的每个人。我们希望不同背景和经验的人都能在项目交流中感到安全、自在。

## Expected behavior / 预期行为

- Be kind, patient, and respectful.
- Discuss ideas and code constructively; criticize the work, not the person.
- Respect differing opinions and experience levels.
- Protect other people's privacy. Do not post private information, personal file paths, or book contents without permission.

- 保持友善、耐心和尊重。
- 建设性地讨论想法和代码；针对问题本身交流，不攻击个人。
- 尊重不同观点和经验水平。
- 保护他人隐私；未经许可，不要发布他人的个人信息、本地文件路径或书籍内容。

## Unacceptable behavior / 不当行为

Harassment, discrimination, threats, personal attacks, unwelcome sexual attention, publishing someone else's private information, and persistent disruptive conduct are not acceptable.

骚扰、歧视、威胁、人身攻击、不受欢迎的性骚扰或性化言行、公开他人隐私，以及持续扰乱项目交流的行为均不可接受。

## Scope / 适用范围

This code applies to project spaces, including Issues, Pull Requests, code reviews, and other project-related communication.

本准则适用于项目空间，包括 Issues、Pull Requests、代码审查及其他与项目有关的交流。

## Enforcement / 执行方式

Maintainers may edit or remove content, close discussions, or restrict participation when conduct violates this code. They will consider the context and seriousness of each report and handle reports as privately as possible.

维护者可根据情况编辑或移除内容、关闭讨论或限制参与。维护者会结合具体情境和严重程度处理，并尽量保护报告者及相关人员的隐私。

## Reporting / 报告问题

Please contact the repository owner privately using a contact method available on the [Nore07 GitHub profile](https://github.com/Nore07). Do not post sensitive details in a public Issue or Pull Request. If you cannot find a private contact method, ask the owner to provide one without naming people or describing the incident publicly.

请通过 [Nore07 的 GitHub 个人资料](https://github.com/Nore07)中提供的联系方式，私下联系仓库所有者。请勿在公开 Issue 或 Pull Request 中发布敏感细节。如果找不到私密联系方式，请先私下询问所有者如何联系；不要在公开页面点名或描述事件。
