# 实时排版与 EPUB 插图

使用独立、非模态的阅读界面面板集中字体、字号、行距、字距、段距和页边距，编辑即预览当前书页；保存才更新设置，取消恢复。保持语义位置，避免滚轮误改，面板尽量位于阅读器旁边。

EPUB 仍不执行原始 HTML，而是把本地图片替换为单字符语义锚点并通过 Qt 文档资源绘制。资源只来自已检查的 ZIP 内路径，保留图文顺序，适配当前页尺寸，限制图片字节、尺寸和解码缓存。支持常见位图及无活动/外部内容的 SVG；内联 SVG 图片包装读取其本地图片。拒绝外链、损坏图像和不安全 SVG。

验证：先失败测试，再检查图像实际像素、图片型章节、错误资源、实时预览/取消/保存、现有回归；运行 Windows 图文与面板冒烟及独立 EXE 验证，按授权提交推送。
