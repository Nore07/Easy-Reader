# 阅读模块与专注模式整理

## 目标

将书籍资料移入阅读模块并排在书签右侧；移除独立浮窗开关，将浮窗行为并入专注模式；把主界面的“偏好”按钮改为“配置”，并保持中英文界面一致。

## 行为约定

- 阅读页签顺序为目录、书签、资料、页码、位置；资料页签仍只在打开书籍后显示。
- 左侧栏只保留阅读导航；书架改为独立主页面，放入阅读区域原来的右侧位置，由“阅读 / 书架”按钮切换。
- 主界面和相关标题/提示统一使用“配置”命名；快捷键与配置内容继续保留。
- 移除独立浮窗按钮和配置项；专注模式作为唯一无边框阅读窗口入口，沿用透明度、背景色/桌面取色和置顶设置。
- 老版本设置文件可继续读取；移除独立浮窗后不再依赖 `floating` 字段决定窗口外观。

## 实施与验证

1. 已先更新 Qt 回归并确认缺失实现时预期失败。
2. 已完成阅读导航重组、书架主页面切换、配置命名更新，以及专注模式与透明度/背景色/取色/置顶设置整合；旧 `floating` 配置会安全忽略。
3. 已更新 README、验收记录和原生/打包冒烟脚本。
4. 已用仓库 `.venv` 验证 95 项 pytest、Windows 原生 Qt 冒烟和 Windows 独立包；提交与推送在阶段验收后执行。

## 验收结果

- 完整 pytest：95 项通过。
- 原生 GUI 冒烟：主界面与书架切换、纯文字专注、0 透明度的桌面合成对照、背景取色、夜读配置、EPUB 目录/页码/资料均通过。
- Windows onedir 包在 `dist/reading-config-focus-final/QuietReader/QuietReader.exe` 构建成功；独立包 `--transparent` 与 `--focus` 场景通过。

## 风险

- 窗口标志改变会影响专注模式的无边框、置顶与退出恢复；Qt 透明 backing store 在原生窗口创建前初始化，并保持启用。
- 旧版设置含 `floating` 字段；升级后须安全忽略或迁移，不能导致窗口意外以专注模式启动。
- 资料页签与 EPUB 页码/位置的索引变化需要同步到既有测试和冒烟脚本。
