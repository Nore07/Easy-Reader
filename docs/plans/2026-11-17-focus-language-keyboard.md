# 专注阅读、语言与按键录入

## 行为

- 正文字色：偏好手动选色，空值继续跟随主题/背景；保存为经过校验的 RGB 十六进制字符串。
- 界面语言：跟随系统、简体中文、英文；翻译应用静态界面、提示、菜单和设置，不翻译书籍内容；加载 Qt 标准控件译文。
- 专注模式：有书时可进入，强制无边框透明背景，仅保留正文；隐藏按钮、标题、侧栏、滑块、状态及尺寸手柄。主按钮及托盘开关、右键菜单、可配置默认 F10 和固定 Esc 可退出。退出恢复原窗口模式、样式及语义位置。专注模式不跨重启自动开启，避免恢复后找不到操作入口。
- 快捷键：通过点击修改、实际按键录入单个按键或组合；统一 Qt PortableText 表示，支持功能键、字母、方向键等，不提供固定选择列表。保留 Esc 退出及打开、偏好、复制的固定组合，检测冲突。全局显示/隐藏键将按 Windows 虚拟键映射注册，不可注册的键明确提示。

## 实施及验证

1. 设置兼容与键解析失败测试；实现字色/语言配置和规范化绑定。
2. 翻译资源、按键捕获、偏好布局；验证录入、取消、冲突和中英文布局。
3. 阅读视图字色和按键处理；实现可恢复的专注模式，不修改书籍正文。
4. 主窗口、托盘、取色和异常提示语言适配；验证切换语言不丢进度。
5. `.venv` 运行完整 pytest，真实 Windows 中英文/专注/按键 GUI 冒烟，重新构建和独立 EXE 冒烟。
6. 检查改动，按已授权规则只提交本阶段文件并推送 origin/main，保留原 IDE 暂存项。

仍需人工确认：Windows 10、不同键盘布局、系统保留快捷键与多屏 DPI。全透明区域的鼠标穿透遵循 Windows 行为；键盘和托盘恢复入口必须可用。

步骤 1–5 已完成：37 项测试、真实 Windows 中英文/录入/专注及原有 GUI 和背景取色冒烟通过。独立 EXE 的英文键盘专注场景和透明启动场景均通过。旧版仍在运行时新版使用独立输出目录，用户数据和原进程保留；最终提交与推送编号见阶段交付。
