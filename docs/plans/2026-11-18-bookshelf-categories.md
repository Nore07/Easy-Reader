# 阅读目录与书架分类

## 目标

将侧栏拆成两个清晰模块：阅读模块包含当前书籍目录和本书书签；独立书架模块包含最近阅读、所有书籍与分类管理。顶部“打开”改为“添加书籍”。用户可创建、选择、移动、删除书架分类，并按选择决定删除分类中的书籍或把书籍移回未分类。

## 约定与边界

- 添加书籍时将 TXT/EPUB **复制**到应用数据目录下的 `书架/未分类/`，保留原始文件。分类管理移动书架内的副本；对旧版状态中还在外部路径的记录，首次分类时复制到书架，保留外部原件。
- 书架目录只用一层：`书架/未分类/` 和 `书架/<分类名>/`。不支持嵌套分类。分类目录是分类名称的持久来源；状态文件记录每本书的路径及最近阅读时间。
- 旧版最近阅读记录继续可见，不在升级时批量复制或移动。旧状态读取兼容；移动路径时同步迁移阅读位置、书签和最后阅读记录的 ID。
- 删除分类时必须让用户明确选择“删除分类及书籍”或“仅删除分类并移回未分类”。只操作书架目录，不删除最初选择的外部原书。删除单本书也只删除书架副本，并有确认提示。
- 分类名限制为单层、合法的文件夹名称，拒绝空名、保留字、路径分隔符及 Windows 不允许字符。重名书籍通过编号生成唯一文件名；不覆盖已有文件。

## 风险与完成标准

- 删除书籍是不可逆的书架副本删除，必须通过应用内明确确认；原始外部文件始终保留。
- 路径更新后阅读位置/书签仍指向同一文本位置；文件移动中途失败时尽量回滚，不能静默覆盖或丢弃文件。
- 所有既有 EPUB/TXT、专注、偏好、透明和导航功能继续通过测试；仅将应用添加到书架的文件纳入书架“全部书籍”。
