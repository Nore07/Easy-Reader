# ADR 0001：Python 本地阅读器

状态：已由用户确认（2026-11-17）。

原规格提供 Electron 推荐，但用户主要熟悉 Python，并明确选择先仅实现本地阅读，采用 Python + PySide6。因此不引入 Node、Electron、Vue 或 AnyReader 运行依赖。

首版用 Qt Widgets 和 QTextDocument 实际测量排版，减少运行组件。EPUB 转为安全纯文本，保留章节和标题/作者；图片、复杂 CSS、原版式不在本阶段。用户不需要单独启动浏览器或服务。

持久化使用本机用户数据目录的版本化 JSON，临时文件 + fsync + 原子替换，并保留上一版备份。小型最近阅读列表无需引入 SQLite；文件正文不落入状态库。未来书签/搜索索引增长时可迁移。

窗口采用原生标题栏保证移动和边缘缩放；浮窗模式使用 Qt Tool 窗口，可单独配置置顶。默认不开启全局快捷键，用户在设置中明确启用后才注册 Ctrl+Alt+R（可改）。

用户后续要求更低干扰的背景，浮窗背景不透明度范围扩展为 0–1，允许全透明；文字和操作按钮不随背景淡化。新增 `background_color`（空字符串表示跟随主题，其他仅允许 `#RRGGBB`），与现有状态版本 1 向后兼容。桌面取色只在用户点击后捕获一次屏幕到内存，选择/取消后立即释放；采用每屏覆盖层并按逻辑坐标与截图尺寸换算像素。保留可见拖动按钮，避免完全透明区域的鼠标穿透影响移动窗口。

专注模式进一步将控件全部隐藏并强制透明，状态只留在当前会话，退出恢复用户的原窗口模式和语义位置；从键盘、托盘或正文右键菜单恢复操作，不在正文上留按钮。新增 `text_color`（空值为自动）、`language`（system / zh_CN / en）及 `focus_key`（默认 F10），继续兼容状态版本 1。所有按键使用 Qt PortableText 的单步组合表示，在共享 keys 模块统一规范化、冲突检测和 Windows 虚拟键转换；录入界面接收真实键盘事件，不维护固定选项列表。应用翻译资源与书籍内容分离，中文/英文切换不修改文件、标题和正文。
